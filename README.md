# One-Line Office Joke: 24-Hour Sprint

Entry for [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) on make.fun.

The program writes one office joke to `/output/entry.txt`:

> Our 'quick sync' has a 47-slide deck, a pre-read, and a follow-up meeting to schedule the follow-up meeting.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
